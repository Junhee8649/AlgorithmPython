# AlgorithmPython

Python으로 알고리즘 문제를 풀이한 코드를 모아둔 저장소입니다.

## 구성

| 폴더 | 플랫폼 | 설명 |
|------|--------|------|
| `Baekjoon/` | [백준 온라인 저지](https://www.acmicpc.net/) | 일반 문제 및 삼성SW 대비 |
| `Programmers/` | [프로그래머스](https://programmers.co.kr/) | 코딩테스트 연습 문제 |
| `Codetree/` | [코드트리](https://www.codetree.ai/) | 삼성SW 기출 |
| `SW Expert Academy/` | [SW Expert Academy](https://swexpertacademy.com/) | SWEA 문제 |

## 폴더 구조

```
.
├── Baekjoon/
│   ├── src/              # 일반 문제
│   ├── 삼성SW대비/        # 삼성SW 역량테스트 대비
│   └── 한번에못푼문제/    # 복습 필요 문제
├── Programmers/          # 프로그래머스 문제 (문제명.py)
├── Codetree/
│   └── 삼성SW기출/
└── SW Expert Academy/
```

## 사용 언어

- Python 3
